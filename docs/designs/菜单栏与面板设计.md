# 左上角菜单栏与面板设计（HOI4 式）

> v0.1｜2026-09-25｜对应实现：game/UI/MenuItemDef.cs、MenuBar.cs、PanelHost.cs、CrewPanel.cs、ResourcePanel.cs、PlaceholderPanel.cs（装配见 Main.SetupMenus）

## 1. 目标与参考

参考钢铁雄心4（HOI4）的顶栏交互范式：**屏幕角落一排入口按钮 + 单窗口互斥面板 + 常显关键资源**。本游戏在左上角布置可扩展菜单栏，未来建造、氧气、资源、人物、政治等全部游戏子系统入口集中于此。

**硬性设计原则**：菜单项与面板**禁止写死数量**——框架在设计之初即支持简易扩展与 UI 自适应；新增一个菜单入口 = 1 个 `MenuItemDef` + 1 个面板类/动作 + 1 行注册，零改动 MenuBar / PanelHost 内部。此原则与项目已有注册制框架（音乐音库 MusicLibraryResource、剧情触发器 CutsceneTriggerRegistry）一脉相承。

## 2. 注册制框架设计

### 2.1 组件职责

| 组件 | 职责 |
| --- | --- |
| `MenuItemDef` | 菜单项数据定义：`Id`（唯一标识，兼作面板注册键）、`DisplayName`、`SortOrder`（排序）、`IconPath`（占位，空=文字按钮，配置后可切图标按钮） |
| `MenuBar`（HBoxContainer） | 注册制按钮栏：`RegisterItem(def, onToggle)` 动态生成 ToggleMode 按钮、按 SortOrder 排列；`UnregisterItem`；`SetPressed(id, pressed)` 供外部状态源同步按钮态；零注册自动隐藏 |
| `PanelHost`（Control） | 互斥面板宿主：`RegisterPanel(id, factory)` 惰性工厂登记（首次打开才实例化）；`Toggle(id)` 互斥单开（开新关旧、再点同项关闭）；`CloseAll`；`PanelVisibilityChanged` 事件供按钮态同步 |
| 装配方（Main.SetupMenus） | 唯一知道具体菜单结构的地方：注册项与面板工厂、接线联动。菜单演进只改此函数 |

### 2.2 扩展流程（三步加一入口）

以未来新增「科研」入口为例：

1. 新建面板类 `game/UI/SciencePanel.cs`（或先用 `new PlaceholderPanel("科研")` 占位）；
2. 在 `Main.SetupMenus` 注册面板：`panelHost.RegisterPanel("science", () => new PlaceholderPanel("科研"));`
3. 注册菜单项：`menuBar.RegisterItem(new MenuItemDef("science", "科研", 5), _ => panelHost.Toggle("science"));`

MenuBar / PanelHost / 其他面板零改动。

### 2.3 动作型入口（无面板）

不开启面板、只执行动作的入口，直接在 onToggle 回调里执行动作而不注册面板（面板工厂可省略），按钮按下态必要时由外部状态源经 `SetPressed` 同步。

## 3. 布局与自适应

- **菜单栏**：左上 (16, 8)，HBox 横排，按钮 CustomMinimumSize 64×32、文字自适应；与顶部居中的时间条（420 宽）在常规分辨率下不重叠。
- **面板区**：菜单栏正下方 (16, 56) 起，互斥单开；面板尺寸 = 内容 CustomMinimumSize 自适应（乘员数变化、资源条目增减自动伸缩）。
- **让位**：DebugOverlay 移至 (16, 320) 且默认隐藏（F3 切换）；**建造面板与其他面板同在左上面板区 (16, 56) 互斥开合，不再常驻左下角**；信息面板（设施/人物）在右侧互斥。
- **溢出预留钩子**（本期不实现）：当注册项过多超出屏宽时，计划将低位项折叠进「≡ 更多」下拉——MenuBar 的全量重建结构（RebuildButtons）即为该演进的接入点。

## 4. 交互

- **互斥单开**：点击菜单钮打开对应面板并关闭其他；再点同一钮关闭。
- **建造联动**：「建造」入口开合建造面板（EditorPanel），**面板可见即处于建造模式**；Main 为唯一协调者——面板可见性 → `MapEditor.EnterEdit/ExitEdit`，反向 `EditModeChanged` → 开合面板与同步按钮态（两侧均有幂等守卫，不会循环触发）；F12 等价于该入口（`MapEditor` 自身切换后经 `EditModeChanged` 把面板一并开合）；切到其他菜单面板会互斥关闭建造面板并自动退出建造模式。
- **人物行选中联动**：乘员总览（CrewPanel）每行 = 姓名[队长★]｜状态｜任务目标，点击行等效点击场景中的角色（复用 OnCharacterPicked：选中圈 + 右侧人物面板 + 取消设施选中）。
- **实时刷新**：乘员行订阅角色/任务状态事件重绘；资源面板订阅余额变化事件刷新。
- **F3**：开发期调试浮层开关（默认隐藏）。

## 5. 面板规格（当前注册项）

| Id | 按钮 | 面板 | 状态 |
| --- | --- | --- | --- |
| build | 建造 | EditorPanel 建造/编辑面板（工具：建造/拆除，开发者模式另有地形/功能区画笔；建造工具下按分类过滤并以「图标+名称」网格选设施） | 真实 |
| crew | 人物 | CrewPanel 乘员总览（行点击联动选中） | 真实 |
| oxygen | 氧气 | PlaceholderPanel | 占位（阶段二生存系统） |
| resource | 资源 | ResourcePanel 备用零件余额 | 真实数据+占位结构 |
| politics | 政治 | PlaceholderPanel | 占位（远期） |

### 5.1 建造面板规格（EditorPanel）

- **工具**：「建造 / 拆除」；开发者模式另有「地形 / 功能区」画笔（正常模式隐藏）。
- **建造流程**：选分类 → 选设施（图标网格，占位色块 + 名称）→ 点地图放置。正常模式放置后设施以「建造中」占位入场并派工建造（工人 + 时间 + 零件随进度实时扣除，进度条显示于设施面板与地图设施底边），建成转「运行」；开发者模式为即时放置（免费，可撤销）。
- **拆除流程**：选「拆除」工具 → 点地图上的设施 → 派工拆除（完成时移除设施并返还建造成本 50%）。
- **分类**：家具 / 电力 / 氧气 / 通信 / 水利 / 建筑物 / 医疗 / 科研（`FacilityCategory`，取自 `FacilityCatalog.Categories`，**无硬编码**；新增分类/设施只改 .tres）。
- **撤销**：仅开发者模式显示按钮且 Ctrl+Z 生效；正常模式完全屏蔽（建造/拆除走任务流程，无撤销语义）。
- **余额**：仅正常模式显示「备用零件：N」。
- **保存地图**：仅开发者模式显示（覆写 `base_map.tres`）；正常模式保存走 ESC 暂停菜单。

## 6. 扩展规划

- **图标化**：MenuItemDef.IconPath 已预留——为按钮配图标素材后从文字按钮切图标按钮，零改框架；
- **常显资源条**：HOI4 顶栏常显关键资源的形态——可在 MenuBar 右侧追加常显标签区（预留为 MenuBar 的兄弟节点，不污染注册结构）；
- **溢出折叠**：见 §3 预留钩子；
- **面板注册表数据化**：若未来面板数量大到不宜集中在 Main.SetupMenus，可演化为 .tres 配置驱动注册（同 demo_config 模式），框架侧无需变更。
